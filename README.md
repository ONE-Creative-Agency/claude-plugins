# ONE Creative Agency · Claude Code plugins

Install (once, in any Claude Code session):

```
/plugin marketplace add ONE-Creative-Agency/claude-plugins
/plugin install one-client-preview@one-agency
```

Update later with `/plugin marketplace update one-agency`.

| Plugin | What it does |
|---|---|
| `one-client-preview` | Client website previews: first-time setup, new preview, send to staging, publish to the client link, passcode page. |
